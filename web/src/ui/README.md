Step 1b: `waveform.ts` owns the canvas/resize/reduced-motion loop; `subtitles.ts` owns word spans, highlighting and the delayed fade. `main.ts` composes these with the existing voice state and conversation records.

Step 2: `mapPanel.ts` mounts the Bind A map (`map/`) under the voice stage with the HUD strip (round/spike timer · Brim's smokes · spike · mode) and a control row (pause, restart, callout labels, designer view). It owns its own `requestAnimationFrame` loop and sim clock, outside any UI state, and skips drawing while the map is off-screen. Hooks from `main.ts`: `isTalking` (Learn mode runs the round at 0.5× while push-to-talk is held), `isBrimSpeaking` (amber pulse on Brim's icon while his TTS plays) and `toggleMode` (the L key flips the voice stage's Learn/Match buttons). Shortcuts P/R/L/D are ignored in text fields; Space stays push-to-talk, and map controls drop focus after a mouse click so a focused button can't swallow Space. Later buy phase and results screens remain deferred.
